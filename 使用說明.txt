菜騎鴨 — 蔬果訂單整理（Windows 10 / 11，64 位元）

第一次使用
1. 將整個壓縮檔解壓縮到電腦，不要直接在壓縮檔內執行。
2. 雙擊「啟動菜騎鴨.exe」，瀏覽器會自動開啟。
3. 點右上角「設定」，貼上自己的 OpenAI API Key，按「儲存金鑰」。
4. 可按「檢查已儲存金鑰」確認金鑰及模型權限。

每天使用
1. 確認出貨日期（預設電腦今天，可手動改日期）。
2. 一次貼一筆客人訊息，每批最多 50 筆；貼上只加入預覽。
3. 確認筆數及內容後，按「整理這 N 筆訂單」。
4. 點配送地點，對照左側原文；右側可編輯明細、新增或刪除商品。
5. 按「儲存明細」，備貨總數會更新。也能用「新增訂單」手動補建訂單。
6. 「匯出 Excel」匯出配送地點、備貨總表及訂單明細；點配送地點可跳至該單明細，再點返回連結回到配送目錄。
   商品金額會與數量分開列出；載具、統編及收貨交代保留於訂單備註。
   無法確定的內容保留提醒。點提醒旁的修改按鈕，可前往需補充的欄位。
   若內容本來就正確，直接按「內容沒問題」清除提醒，可按「復原提醒」還原。
7. 「展開配送清單」可查看所有訂單地點；點地點查看該單原文。
8. 「展開備貨清單」顯示商品總量與各單分量。點商品卡片或勾選框標記已備妥，再點一次恢復。
   點訂單編號標籤可查看原文；訂單標籤採 12 色循環，以編號辨識不同訂單。
   完成狀態會暫存在目前瀏覽器；數量或分單內容變更後需重新確認受影響品項。
   「商品排序」把相近商品排在一起，再按「還原順序」恢復。
9. 配送與備貨清單均可按「複製文字」，取得清楚編號、條列的文字供貼上分享。
   備貨文字包含總量、各單分量及完成狀態。若瀏覽器不允許自動複製，會顯示可手動複製的文字。
10. 用完可在「設定」按「關閉程式」。只關閉瀏覽器分頁不會結束本機服務。

重要事項
• 不需要安裝 Python、Node.js 或 Excel；匯出的 .xlsx 可交給 Excel 開啟。
• AI 整理需要網路和自己的 OpenAI API 可用額度，費用由該 Key 帳戶支付。
• 只有按下整理，才會將尚未手動修正的訂單原文送至 OpenAI。
• AI 可能辨識錯誤，請對照原文確認商品、數量、單位及處理方式。
• 已儲存的手動修正會保留；修改該筆原文後，需重新整理該筆。
• 金鑰以 Windows 使用者加密，存放在 %LOCALAPPDATA%\CaiQiYa\key.dat。
  設定頁不會顯示已儲存的 Key，壓縮檔和 Excel 都不包含 Key。
  換電腦或換 Windows 帳號後，請重新貼上 Key。
• 訂單暫存在目前瀏覽器。請固定用同一瀏覽器；清除網站資料會清除暫存訂單。
  需要長期保留的資料，請匯出 Excel 保存。
• 程式只接受本機連線，不提供其他電腦連入。

遇到問題
• 沒開啟網頁：確認程式執行後，開啟 http://127.0.0.1:18765/。
• Key 無效：在設定重新貼上有效 Key。
• 額度不足／請求過多：查看 OpenAI 帳戶額度，稍後再試。
• 內容不明：修改原文後重新整理。日期未填不會阻擋。
• Windows 若攔截未簽章程式，請先確認檔案來源；此版本尚未購買程式碼簽章。

整理模型：GPT-6 Luna（gpt-6-luna），低推理強度。需 API 專案具備使用權限。

備貨時按「展開備貨清單」，以大畫面多欄顯示整批商品與合計數量。即使原本選取單筆訂單，也會顯示全部訂單；加工方式、單位不同會分列。按「返回訂單」或 Esc 回原畫面。
